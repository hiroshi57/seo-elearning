テクニカルSEO

サイト構造：URL、内部リンク、XMLサイトマップ、canonical、クローラの制御、表示速度：Core Web Vitals、セキュリティ：HTTPS

8 / 8

まとめ

  • GoogleはわかりやすくPredictableなURL構造を推奨しており、サイトの構成を反映した短く明確なURLが望ましい
  • 内部リンクはクローラーがページを発見する手がかりにもなり、孤立したページを作らないことが重要
  • XMLサイトマップには正規URL（canonicalで指定したURL）のみを含めるべきで、canonicalタグは重複コンテンツの整理に使う
  • meta robotsやrobots.txtでクローラの動きを制御できるが、すべてのAIbotが指示に従う保証はない
  • Core Web Vitalsは読み込み速度（LCP）・応答性（INP）・視覚的安定性（CLS）の3指標で構成され、実際のユーザーデータをもとに評価される
  • Core Web Vitalsは2021年6月からランキングシグナルとして使用されており、指標も更新される（2024年3月にFIDがINPへ置き換え）
  • GoogleはHTTPS化を2014年からランキングシグナルとして使用しているが、コンテンツの品質などと比べると影響は軽微な、軽量シグナルである
